Attractor

definition · editorial · qeva:1:attractor@1

An attractor is an invariant set approached by trajectories from a nontrivial basin, under a specified definition.

dynamics · systems

Plain → exact → dependencies

Plain. An attractor is long-run structure toward which many permitted starting states move.

Exact. One common definition: a compact invariant set A is an attractor if there exists a neighborhood U of A such that dist(F^n(x),A)→0 for every x∈U, often with an additional minimality condition.

Framework
metric dynamical systems
Assumptions
A dynamical system, invariant set A, metric, and basin notion are specified.
Dependencies
none declared
Relations
related-to → qeva:1:stability@1 (Attracting behavior is analyzed together with stability.); can-be → qeva:1:fixed-point@1 (A stable fixed point may be an attractor.)
Example
For F(x)=x/2 on R, {0} is an attractor for all initial x.
Caveat
Attractor definitions vary across dynamical-systems literature; “strange attractor” additionally needs explicitly stated properties.

Chirality

definition · editorial · qeva:1:chirality@1

Failure of an object to be superimposable on its mirror image using only orientation-preserving transformations.

symmetry · geometry

Plain → exact → dependencies

Plain. A chiral object has a handedness: mirroring changes it in a way that allowed orientation-preserving motions cannot undo.

Exact. For x in X, define the mirror image r·x. The object x is chiral relative to (G,H) iff r·x is not in the H-orbit H·x. Because H has index 2, the property is independent of which r in G\H is chosen.

Framework
group actions with orientation class
Assumptions
A group G acts on X.; H is an index-2 subgroup of orientation-preserving transformations.; r is any element of G\H.
Dependencies
qeva:1:symmetry@1
Relations
none
Example
Left and right hands are the usual physical analogy: a mirror swaps handedness, while rotations alone do not.
Caveat
Chirality is relative to a declared transformation group and an orientation-preserving subgroup; it is not an intrinsic word without that context.
Verification

Quasiperiodicity

definition · editorial · qeva:1:quasiperiodicity@1

A context-dependent torus-frequency representation often used for recurrent behavior with several incommensurate frequencies.

dynamics · analysis · sequence

Plain → exact → dependencies

Plain. A common quasiperiodic model combines several angular motions whose basic frequencies are rationally independent. The representation itself must be distinguished from the extra conditions needed to guarantee that the resulting function is nonperiodic.

Exact. Under this convention, f:R->X has a quasiperiodic torus representation when f(t)=F(theta_0+omega t), where F:T^k->X, theta_0 in T^k, and omega in R^k. Nonperiodicity of f does not follow from that condition alone if F has additional symmetries or degeneracies.

Framework
quasiperiodic functions on R
Assumptions
F:T^k→X is periodic in each angular coordinate, where T=R/(2πZ).; ω in R^k is a frequency vector.
Dependencies
qeva:1:periodicity@1
Relations
none
Example
f(t)=cos(t)+cos(sqrt(2)t) is nonperiodic and has a two-frequency quasiperiodic representation under this convention.
Caveat
“Quasiperiodic” has other precise meanings in tilings, symbolic dynamics, cocycles, and other areas. Each use must state its convention.

Stability

definition · editorial · qeva:1:stability@1

Stability asks whether specified behavior persists under sufficiently small perturbations.

dynamics · analysis · control

Plain → exact → dependencies

Plain. A stable behavior does not immediately lose its qualitative or quantitative character after a small perturbation.

Exact. For a fixed point x* of a map F on a metric space, Lyapunov stability means: for every ε>0 there exists δ>0 such that d(x0,x*)<δ implies d(F^n(x0),x*)<ε for all n≥0.

Framework
metric dynamical systems
Assumptions
A notion of perturbation, a reference behavior, and a time evolution are specified.

For F(x)=x/2 on R, x*=0 is asymptotically stable.
Caveat
