This is a deliberately small seed atlas demonstrating the QEVA record grammar. These entries are not claimed to be the unique foundations of mathematics.

Important: context-dependent concepts are marked explicitly. QEVA would rather preserve an honest boundary than manufacture a false universal definition.

Chaos

terminology · context-dependent

A family of precise but non-equivalent dynamical notions rather than one universal predicate.

dynamics · chaos

Exact record

Context. Context-specific; no single formal system declared.

Assumptions. None beyond the stated context.

Exact. QEVA Protocol 0.1 assigns no universal predicate Chaos(T). A record claiming chaos must identify a contextual criterion (for example a named topological, measure-theoretic, symbolic, or metric definition) and state its hypotheses.

Caveat. Popular descriptions such as “random-looking” or “small errors grow” are not by themselves mathematical definitions of chaos.

Chirality

definition · formalized

Failure of an object to be superimposable on its mirror image using only orientation-preserving transformations.

symmetry · geometry

Exact record

Context. group actions with orientation class

Assumptions. A group G acts on X.; H is an index-2 subgroup of orientation-preserving transformations.; r is any element of G\H.

Exact. For x in X, define the mirror image r·x. The object x is chiral relative to (G,H) iff r·x is not in the H-orbit H·x. Because H has index 2, the property is independent of which r in G\H is chosen.

Caveat. Chirality is relative to a declared transformation group and an orientation-preserving subgroup; it is not an intrinsic word without that context.

Equivalence relation

definition · formalized

A precise way to declare when two elements are treated as the same for a specified purpose.

logic · structure

Exact record

Context. standard set-theoretic mathematics

Assumptions. None beyond the stated context.

Exact. For a set X, a relation ~ on X is an equivalence relation iff (i) for every x in X, x~x; (ii) for all x,y in X, x~y implies y~x; and (iii) for all x,y,z in X, x~y and y~z imply x~z.

Halving

concept · context-dependent

The inverse problem to doubling, defined only when the ambient structure makes division by 2 meaningful or solvable.

number · algebra · structure

Exact record

Context. Context-specific; no single formal system declared.

Assumptions. None beyond the stated context.

Exact. Given a structure with an addition operation, y is a half of x when y+y=x. A unique halving operation x↦x/2 exists only in contexts where this equation has exactly one solution y for each x under consideration.

Caveat. The existence and uniqueness of halves depend on the ambient algebraic structure.

Invariant

definition · formalized

A quantity or property unchanged by a specified family of transformations.

symmetry · structure · dynamics

Exact record

Context. group actions

Assumptions. A group G acts on a set X.; A function I maps X to a set Y.

Exact. I:X→Y is invariant under G iff for every g in G and x in X, I(g·x)=I(x).

Caveat. Changing the transformation family changes which quantities qualify as invariants.

Parity

definition · formalized

Classification of integers by their remainder modulo 2.

number · arithmetic

Exact record

Context. integers with ordinary arithmetic

Assumptions. None beyond the stated context.

Exact. For n in Z: n is even iff there exists k in Z with n=2k. n is odd iff there exists k in Z with n=2k+1.

Periodicity of a sequence

definition · formalized

Exact repetition after a fixed positive index shift.

dynamics · sequence · recurrence

Exact record

Context. sequences indexed by integers or natural numbers

Assumptions. A sequence (a_n) has an index domain on which n+p is defined for the stated n.

Exact. A sequence (a_n) is periodic with period p>0 iff a_{n+p}=a_n for every index n for which both terms are in the domain. A least positive such p, when it exists, is called the fundamental period.

Caveat. Continuous functions, group actions, tilings, and dynamical systems use related but context-specific notions of periodicity.

Prime number

definition · formalized

A positive integer greater than 1 with no positive divisors other than 1 and itself.

number · arithmetic

Exact record

Context. positive integers with ordinary multiplication and divisibility

Assumptions. None beyond the stated context.

Exact. For p in Z with p>1, p is prime iff for every positive integer d, d divides p implies d=1 or d=p.

Caveat. This seed record uses the standard positive-integer definition; “prime elements” in general rings require separate contextual definitions.

Quasiperiodicity

definition · context-dependent

A context-dependent form of recurrent nonperiodic behavior generated by multiple incommensurate periods or frequencies.

dynamics · analysis · sequence

Exact record

Context. quasiperiodic functions on R

Assumptions. F:T^k→X is periodic in each angular coordinate, where T=R/(2πZ).; ω in R^k is a frequency vector.

Exact. In this record, f:R→X is quasiperiodic when f(t)=F(ω_1 t,...,ω_k t) for a function F on the k-torus and a frequency vector ω whose components are rationally independent: if m in Z^k and m·ω=0, then m=0.

Caveat. “Quasiperiodic” has other precise meanings in tilings, symbolic dynamics, cocycles, and other areas. Those require separate records rather than silently reusing this definition.

Recurrence relation

definition · formalized

A relation constraining indexed values using other indexed values, often earlier ones.

dynamics · sequence · computation

Exact record

Context. standard discrete mathematics

Assumptions. A sequence or family of indexed values is specified.

Exact. A recurrence relation for a sequence (a_n) is a relation R(n,a_n,a_{n-1},...,a_{n-k}) that is required to hold for specified n. A recurrence plus initial conditions may determine the sequence.

Sensitive dependence on initial conditions

definition · formalized

A metric dynamical property in which arbitrarily nearby starting states can eventually separate by a fixed positive amount.

dynamics · chaos · analysis

Exact record

Context. metric dynamical systems

Assumptions. (X,d) is a metric space.; T:X→X is a map.

Exact. T has sensitive dependence on initial conditions iff there exists δ>0 such that for every x in X and every ε>0 there exist y in X and n>=0 with d(x,y)<ε and d(T^n(x),T^n(y))>δ.

Caveat. Sensitivity alone is not a universal definition of chaos.

Symmetry

definition · formalized

A transformation that leaves a specified object unchanged relative to a specified action.

symmetry · structure

Exact record

Context. group actions

Assumptions. A group G acts on a set X.; An object x belongs to X.

Exact. The symmetry group of x relative to the action of G on X is Stab_G(x) = { g in G : g·x = x }.

Caveat. Symmetry depends on the chosen object representation and transformation group.
