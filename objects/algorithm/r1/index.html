Algorithm

An algorithm is a finite description of an effective step-by-step procedure for a class of inputs.

editorialcomputation · logic

PLAIN

The idea

An algorithm is a finite description of an effective step-by-step procedure for a class of inputs.

EXACT

The compact statement

A precise algorithm fixes an input representation, transition rules, output condition, and halting behavior; formal models include Turing machines and recursive functions.

EXAMPLE

Euclid's algorithm repeatedly replaces (a,b) by (b,a mod b) until b=0.

BOUNDARY / CAVEAT

An informal recipe is not automatically an algorithm until its steps and representations are unambiguous.
