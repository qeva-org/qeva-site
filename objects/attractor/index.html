DEFINITION · qeva:1:attractor@2

Attractor

An attractor is an invariant set approached by trajectories from a nontrivial basin, under a specified definition.

editorialdynamics · systems

PLAIN

The idea

An attractor is long-run structure toward which many permitted starting states move.

EXACT

The compact statement

One common definition: a compact invariant set A is an attractor if there exists a neighborhood U of A such that dist(F^n(x),A)→0 for every x∈U, often with an additional minimality condition.

EXAMPLE

For F(x)=x/2 on R, {0} is an attractor for all initial x.

BOUNDARY / CAVEAT

Attractor definitions vary across dynamical-systems literature; “strange attractor” additionally needs explicitly stated properties.

ASSUMPTIONS

  • A dynamical system, invariant set A, metric, and basin notion are specified.
