DEFINITION · qeva:1:chirality@2

Chirality

Failure of an object to be superimposable on its mirror image using only orientation-preserving transformations.

editorialsymmetry · geometry

PLAIN

The idea

A chiral object has a handedness: mirroring changes it in a way that allowed orientation-preserving motions cannot undo.

EXACT

The compact statement

For x in X, define the mirror image r·x. The object x is chiral relative to (G,H) iff r·x is not in the H-orbit H·x. Because H has index 2, the property is independent of which r in G\H is chosen.

EXAMPLE

Left and right hands are the usual physical analogy: a mirror swaps handedness, while rotations alone do not.

BOUNDARY / CAVEAT

Chirality is relative to a declared transformation group and an orientation-preserving subgroup; it is not an intrinsic word without that context.

ASSUMPTIONS

  • A group G acts on X.
  • H is an index-2 subgroup of orientation-preserving transformations.
  • r is any element of G\H.
