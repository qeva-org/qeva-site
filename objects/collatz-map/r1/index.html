DEFINITION · qeva:1:collatz-map@1

Collatz map

A piecewise integer map sending even n to n/2 and odd n to 3n+1.

editorialnumber-theory · dynamics · computation

PLAIN

The idea

Collatz dynamics repeatedly applies one of two arithmetic rules depending on parity.

EXACT

The compact statement

T(n)=n/2 if n is even, and T(n)=3n+1 if n is odd, for n∈N_{>0}. The orbit is n,T(n),T^2(n),....

EXAMPLE

Starting at 6: 6→3→10→5→16→8→4→2→1→4→2→1→...

BOUNDARY / CAVEAT

The map is deterministic and discrete, but calling it chaotic requires a separate precise definition and proof.

ASSUMPTIONS

  • n is a positive integer.

PROVENANCE

Seed record for the QEVA machinery map. It is not claimed to be the unique foundational presentation of this concept.
