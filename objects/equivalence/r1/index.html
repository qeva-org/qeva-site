DEFINITION · qeva:1:equivalence@1

Equivalence relation

A precise way to declare when two elements are treated as the same for a specified purpose.

editoriallogic · structure

PLAIN

The idea

A relation is an equivalence relation when it behaves like equality with respect to reflexivity, symmetry, and transitivity.

EXACT

The compact statement

For a set X, a relation ~ on X is an equivalence relation iff (i) for every x in X, x~x; (ii) for all x,y in X, x~y implies y~x; and (iii) for all x,y,z in X, x~y and y~z imply x~z.

EXAMPLE

Congruence modulo 2 partitions the integers into the even and odd equivalence classes.
