DEFINITION · qeva:1:fixed-point@2

Fixed point

A fixed point is a state left unchanged by a map.

editorialdynamics · analysis · computation

PLAIN

The idea

A fixed point reproduces itself after one application of the update rule.

EXACT

The compact statement

x*∈X is a fixed point of F iff F(x*)=x*.

EXAMPLE

For F(x)=x^2 on R, 0 and 1 are fixed points.

BOUNDARY / CAVEAT

A fixed point may be stable, unstable, attracting, repelling, or neutral depending on additional structure and the chosen stability notion.

ASSUMPTIONS

  • A set X and a map F:X→X are specified.
