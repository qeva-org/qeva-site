Function

A function assigns exactly one output to each permitted input.

editorialfoundations · structure

PLAIN

The idea

A function assigns exactly one output to each permitted input.

EXACT

The compact statement

A function f:X→Y may be represented by a relation f⊆X×Y such that every x∈X occurs in exactly one pair (x,y) with y∈Y.

EXAMPLE

f(n)=n+1 defines a function from integers to integers.

BOUNDARY / CAVEAT

A rule, graph, program, and extensional mapping can represent a function differently.
