Self-information

A less probable event carries more self-information under a logarithmic coding model.

editorialinformation-theory · probability

PLAIN

The idea

A less probable event carries more self-information under a logarithmic coding model.

EXACT

The compact statement

For event E with 0<P(E)≤1, I(E)=−log_b P(E); the base b fixes units such as bits when b=2.

EXAMPLE

A fair coin result carries 1 bit of self-information.

BOUNDARY / CAVEAT

This technical quantity is not identical to meaning, knowledge, usefulness, or truth.
