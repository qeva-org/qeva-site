DEFINITION · qeva:1:nonlinearity@1

Nonlinearity

A map is nonlinear when it fails the defining linearity conditions of additivity and scalar homogeneity.

editorialalgebra · dynamics · optimization

PLAIN

The idea

In a nonlinear system, combining inputs need not combine outputs by simple superposition.

EXACT

The compact statement

A map f:V→W is linear iff f(ax+by)=af(x)+bf(y) for all x,y and scalars a,b. It is nonlinear if this condition fails.

EXAMPLE

f(x)=x^2 on R is nonlinear because f(x+y) generally differs from f(x)+f(y).

BOUNDARY / CAVEAT

Nonlinearity alone does not imply complexity, instability, or chaos.

ASSUMPTIONS

  • Vector spaces and a map f between them are specified.
