DEFINITION · qeva:1:satisfaction@1

Satisfaction

A semantic relation stating that a formula holds in a declared interpretation or model.

editoriallogic · semantics · foundations

PLAIN

The idea

A formula can be true in one mathematical structure and false in another. QEVA must name the semantics or model when it uses semantic truth.

EXACT

The compact statement

The notation M |= P denotes that P is satisfied by model M according to the declared semantic clauses for the language in use.

EXAMPLE

A sentence about order can hold in one ordered structure and fail in another.

BOUNDARY / CAVEAT

The symbol |= has framework-specific semantics. A QEVA record must not silently identify semantic truth with formal provability.

ASSUMPTIONS

  • A language, an interpretation/model M, and a formula P suitable for that semantics are fixed.

PROVENANCE

Seed record written to make QEVA Protocol 0.2 explicit. It is an editorial mathematical formulation, not a claim that one foundation is uniquely privileged.
