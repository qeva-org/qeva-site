DEFINITION · qeva:1:sequence@2

Sequence

An ordered family of values indexed by a specified set, usually the natural numbers.

editorialstructure · number · dynamics

PLAIN

The idea

A sequence is not merely a written list; mathematically it is a function whose input is an index.

EXACT

The compact statement

A sequence in X indexed by I is a function a:I→X. When I=N, the value at n is written a_n.

EXAMPLE

The sequence 1,2,4,8,... can be represented by a_n=2^n for n=0,1,2,...

BOUNDARY / CAVEAT

Indexing and order are part of a sequence; the same collection of values can define different sequences, and an infinite sequence is not established by a finite prefix.

ASSUMPTIONS

  • An index set I and codomain X are specified.
