PLAIN

The idea

A statement is an expression eligible to be asserted, denied, proved, or evaluated in a model.

EXACT

The compact statement

For a language L, Sent(L) is the class of closed well-formed formulas: formulas with no free variables.

EXAMPLE

∀x (x=x) is a sentence in a language with equality.

BOUNDARY / CAVEAT

The same written string may fail to be a statement in another grammar.
