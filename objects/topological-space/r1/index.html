Topological space

A topology declares which regions count as open, encoding nearness without requiring numerical distance.

editorialtopology · analysis

PLAIN

The idea

A topology declares which regions count as open, encoding nearness without requiring numerical distance.

EXACT

The compact statement

A topology τ on X contains ∅ and X, is closed under arbitrary unions, and under finite intersections; (X,τ) is a topological space.

EXAMPLE

Every metric induces a topology through open balls.

BOUNDARY / CAVEAT

Different topologies on the same set create different continuity and convergence behavior.
