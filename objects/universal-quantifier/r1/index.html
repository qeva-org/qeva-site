Universal quantifier

Universal quantification requires a statement to hold for every permitted value in a domain.

editoriallogic

PLAIN

The idea

Universal quantification requires a statement to hold for every permitted value in a domain.

EXACT

The compact statement

Given formula φ(x), ∀x φ(x) is satisfied in M when φ holds under every assignment of a domain element to x.

EXAMPLE

∀n∈ℕ, n+0=n.

BOUNDARY / CAVEAT

The domain and variable range must be recoverable.
