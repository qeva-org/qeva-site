PRESERVATION

The domain is disposable.

QEVA survives only if the archive can outlive qeva.org, GitHub, Vercel, current cryptography, and the organization that created it.

Preservation model

QEVA = protocol + open archive + independent mirrors + snapshots + institution + right to fork

Canonical requirements

  1. Records remain readable as documented UTF-8 text.
  2. A complete archive can be copied without permission.
  3. Every release includes machine-verifiable manifests.
  4. Mirrors must be administratively and geographically independent.
  5. No proprietary service is required to decode the archive.
  6. Format migration preserves old bytes and records the conversion.
  7. Physical snapshots include enough bootstrap information to explain how the archive is encoded.

Mirror QEVA

Copy this repository or only the preservation-critical subset: protocol/, archive/, snapshot/, and licenses. Serve it publicly if possible. A mirror may use any software.

git clone <official-or-mirror-repository>
cd qeva-site
python3 scripts/verify.py

Git is useful today but is not part of the permanent protocol. A plain directory copy is sufficient.

Snapshots

A snapshot should contain the complete archive, protocol version, schemas, manifests, licenses, and the self-describing bootstrap document. Multiple media and multiple custodians are preferred over confidence in any single “permanent” medium.
